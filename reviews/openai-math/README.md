## Caveats, in one place
- One model-assisted reading per family, validated mechanically; six families re-read by hand; no referee yet. The error rate is measured next.
- `full` means the Lean states the headline; it does not say the mathematics is correct beyond what Lean checked, nor that every hand-built definition is the textbook one (those are listed under "definitions to check").
- Comparator runs so far used the development landrun shim (no sandbox). A sandboxed Linux run is pending.
- The audit JSON uses the field names `gap_note` and `suspicious_defs`; the public tables call them `review_note` and `definitions_to_check`. Same content.
